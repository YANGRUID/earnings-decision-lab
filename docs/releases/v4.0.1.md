# Earnings Decision Lab v4.0.1 — Post-release fixes

Patch release on top of v4.0.0 (same methodology, same six configurations, same 15:30 ET
decision and T+1 15:30 ET settlement with settlement priority). No performance claim.

## Fixed
- **Earnings calendar:** tickers, day numbers and the "+N more" overflow open a full day table
  (every company reporting that day, timing, market cap, estimates, V4 pipeline state and
  windows); tickers link to the company workspace. The old chips pointed at a route retired in
  the V4-only reset.
- **Pipeline feed:** forward-only by default — windows still open or ahead plus every event with
  real V4 evidence. Pre-activation rows (decision window missed before V4 existed) are no longer
  product rows; `include_past=true` returns the complete monitoring view.
- **Brand mark:** white-background mark by default (README, tab icon as a classic BMP
  `favicon.ico` + PNG links); sidebar navy tile on the light theme, white mark on the dark theme.
- **Eastern time** for the Dashboard decision/settlement columns and the forward-window card.
- **CI:** official IBKR TWS API client fetched before `uv sync`; retired-job migrations tolerate
  a fresh database; backend tests run against an isolated CI test database.

## Known limitations
Unchanged from v4.0.0: tiny forward sample, delayed market data, class-share resolution edge
cases, shared strategy-family universe for Aggressive and Moderate, no order execution.
