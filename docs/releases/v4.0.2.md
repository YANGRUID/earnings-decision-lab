# Earnings Decision Lab v4.0.2 — Earnings estimates from the calendar first

Patch release on top of v4.0.1 (same methodology, six configurations, 15:30 ET windows with
settlement priority). No performance claim.

## Fixed
- **Earnings estimates no longer depend on Alpha Vantage's daily quota.** The research
  preparation step now takes the next report date and the EPS / revenue consensus from the
  EarningsAPI earnings calendar first (`date_source = EARNINGS_CALENDAR`); Alpha Vantage is
  consulted only when the calendar has no upcoming report for the company. Lululemon's
  "malformed row … rate-limit-degraded CSV shape" warning was exactly this: the free tier's
  25 requests a day had been consumed by the worker although the calendar already knew the date
  and the estimates.
- Data Providers shows the new order (EarningsAPI primary, Alpha Vantage fallback).

## Known limitations
Unchanged from v4.0.1.
